# Выполненное тестовое задание от Ареал на написание приложения по импорту Excel в SQL базу данных.

Тестовое задание: WPF приложение для импорта данных из Excel-журнала в существующую SQLite базу данных с отображением данных в DataGrid.

## Стек технологий

- **.NET Framework 4.7.2** — целевая платформа
- **WPF** — пользовательский интерфейс
- **System.Data.SQLite.Core** — работа с SQLite БД
- **EPPlus** — импорт Excel файлов (.xlsx, .xls)
- **xUnit** — модульное тестирование
